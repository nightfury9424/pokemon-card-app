## 1. 한 줄 정의
포켓폴리오 앱 안에 **"오리파"라는 서브앱(독립 서비스)을 새로 여는 것.** 토스 = 은행앱인데 증권 탭 들어가면 잔액·자산·세계관이 딴 서비스인 그 느낌. 진입만 MY, 그 뒤는 독립 세계.

## 2. 사업 모델 (합의 완료)
오프라인 카드매장 **입점 중개**. 사장님이 오리파 1~100 전부 정함(가격·구수·상품·번호·연출), 우리는 틀+결제(포인트)+추첨+관제만. **추첨·돈=플랫폼 / 재고·배송=매장.** 판매 시작 후 구성 동결, 포인트 교환가 LOCKED.

## 3. 오리파 상품 도메인 = 포켓폴리오 자산 DB와 **완전 분리** (★재발 방지 1순위)
- 오리파 상품은 사장님이 **직접 등록**(사진 업로드+이름+수량+교환P). 카드 DB 검색·참고가·환원율 강제 전부 없음.
- 상품 = 카드 DB에 없는 슬랩·미개봉 박스·팩·굿즈까지 가능.
- 유저 화면에서 **"내 카드" 금지 → "내 보관함 / 보관 중인 상품".** 기존 MY 내 카드와 섞으면 처음 문제로 회귀.
- DB에 `cards.card_id` FK 강제 금지. (나중에 "이 상품 카드와 연결?" 부가기능은 가능, 전제조건 아님)

## 4. 오리파 2종 — **완전히 별개의 실물 경험** (한 파일 if OPEN/CLOSED로 묶지 말 것)
공통은 **덮개 카드를 손으로 조금씩 내리는 물리 동작 하나뿐.** 깐 결과의 의미가 다름.

### 4-A. 번호 오리파 (오픈형)
- 판 A(상품 전시판): 번호별 실제 상품이 **다 보임**(투명성), 뽑힌 번호=빈자리. **좋은 상품 남았나 확인 = 오픈형 본질, 반드시 유지.**
- 깐 것 안에는 상품이 아니라 **일반 RR 카드 + 흰 번호 스티커**(번호 운반체. 유저 지급 여부 미정 — 덤 확정 금지).
- 번호 → 판 A의 그 번호 상품이 내 것.
- **모바일 UX 확정**: 판 B(봉인물 100칸 직접 선택 그리드)는 **삭제**(좁은 폰에서 노동). 대신 [1구 뽑기] → **봉인 카드 더미에서 한 장 자동 추출**(직원이 덱에서 꺼내주는 느낌). 까는 건 유저 손. → 선택=자동, 까기=유저.
- 웹 프로토타입 `oripa_number.html`에 이 손맛/모션 검증됨(가챠 요소 0).

### 4-B. 상품 봉인 오리파 (비공개형) — 아직 미구현
- 상품이 포장돼 안 보임. 결과판·번호·투명성 없음.
- 깐 것 안에 **실제 상품 카드가 직접**. 덮개 내리면 상품이 위에서부터 드러남.
- 긴장 = "내 봉인물 안에 뭐가 들었나."

### ★금지 (전 방식 공통) — 가챠 사고 재발 방지
티어·JACKPOT·암전·파티클·빛한줄·룰렛·슬롯머신·morph·플립 연출 전부 금지. 긴장은 내재적(내 번호가 비싼 상품에 걸리나 / 내 봉인 안에 뭐가). 강조는 잔잔한 것만.

## 5. 앱 IA (진입 확정 — 다시 A/B 묻지 말 것)
```
MY → [오리파]
  → 오리파 홈 (독립 서비스 홈)
        · 상단: 내 포인트 잔액 + [포인트 충전]
        · 내 보관함 (보관 중인 상품 N개, 매장별)
        · 매장별 무료배송까지 남은 P / 배송 현황
        · [오리파 하러가기]  ← 메인 CTA
        · 최근 이용/포인트/배송 내역
  → 매장 목록 (몬스터카드 홍대점·진행 3개 / 카드월드 강남·5개 …)
  → 매장 상세 (그 매장 진행 중 오리파: 1구 가격·남은 구수·대표 상품)
  → 오리파 상세 (상품판 투명성)
  → 뽑기 (번호 오리파 먼저. 상품 봉인형은 나중)
  → 결과 → [보관하기] / [포인트 교환] → 오리파 홈 반영
```

## 6. 이번(다음 세션) 목표 = **뼈대 5화면 Flutter mock 연결**
- 결제·백엔드·DB·실제 추첨 **전부 없이** mock data로 화면 전환만.
- 실기기에서 "토스 증권 들어온 것처럼 다른 서비스"가 느껴지는지가 목표.
- 뽑기(번호 오리파 손맛)는 뼈대 OK 나온 뒤 마지막에 붙임. 상품 봉인형은 아직 안 건드림.
- **뽑기가 아니라 오리파 홈이 먼저** 있어야 함. 홈 자산 = 포인트 + 보관함 + 매장별 배송상태.
