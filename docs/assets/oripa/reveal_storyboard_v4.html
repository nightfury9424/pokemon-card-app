뒷면에 금빛 후광이 돌면 HIT — 검은 무대에선 문구가 하나씩

v3 3가지 교정: ①문구 누적 폐기 → 한 개씩만(이전 사라지고 다음), ②아우라 = 세나식 금빛 후광(카드 뒤 광륜+골드 입자+테두리 발광, 얇은 링 아님), ③카드 올라온 뒤 팩 잔해 제거. 카드백은 프리미엄 오르네이트로 교체 — NORMAL/HIT 동일, 뒤 후광만 차이.

① 문구 한 개씩

검은 무대에 항상 clue 1개. 이전 문구 사라지고 다음 등장. 누적 UI 아님.

② 금빛 후광

세나 카드백처럼 카드 뒤 소프트 골드 광륜 + 보케 입자 + 테두리 발광. 후광만 보고 HIT 인지.

③ 팩 잔해 제거

카드가 주인공 되는 순간부터 팩 하단·꼬리 안 남김. HERO엔 팩 없음.

  • none — 후광 없음(NORMAL)
