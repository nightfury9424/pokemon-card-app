## 제품 구조: `공지 | 자유` 2탭 (기본 = 자유)
전체 피드 폐기. `거래후기/사기주의/Q&A` 탭·작성 type 선택 제거. 서버·DB type(notice/event/patch/free/tradeReview/scamAlert/qna)·컬럼은 **삭제 안 함**(향후 확장). **Q&A 답변 채택 = 1.0.4 구현 제외**(스키마·설계 흔적만 유지).

## 1. 공지게시판 (운영 전달용 · 읽기 전용)
- 앱 사용자 = **읽기만**. 앱에 작성/수정/삭제/댓글/좋아요 UI **없음**.
- 공지 작성·수정·삭제·고정 = **관리자 웹페이지에서만**. 타입 notice/event/patch → 앱 배지 공지/이벤트/업데이트.
- 조회 = `GET /api/board/posts?section=official`. **고정글 우선 → 최신순**.
- ★**서버 가드(필수)**: official 글에 일반 사용자의 **댓글·좋아요·수정/삭제 요청을 거부**. (현재 `createComment` 미차단 = 갭 → 가드+테스트 추가.)
- 홈 공지 영역도 동일 official API(고정 우선·최신).
- ★**완료 정의**: 관리자 API만이 아니라 **관리자 웹에 공지 목록·작성·수정·삭제·고정 UI 실구현**까지.

## 2. 자유게시판 (일반 커뮤니티)
- 열람 = 전체. 작성 = **로그인 전원**. 수정·삭제 = **작성자 본인만**.
- 조회 = `GET /api/board/posts?type=free`. 글쓰기 화면 type 선택 없이 **`free` 고정**.
- 댓글 + **1단 대댓글**. 본인 댓글·대댓글 삭제. 관리자 숨김·복구·삭제.
- **좋아요/추천**(목업 '추천' = 서버 `likeCount`). 신고·차단·금칙어 적용.
- 목록 = 댓글 수·좋아요 수 표시. 상세 = 내 좋아요 여부(liked) 포함.

### 좋아요 규칙 (백엔드 신규 — 현재 토글 API·dedup 없음)
- 로그인 사용자만 · 사용자당 게시글 **1회** · 다시 누르면 **취소(토글)** · DB unique(또는 동등)로 **중복 집계 금지**(동시요청 포함) · 목록·상세 likeCount **일치** · 상세에 현재 사용자 liked 포함 · **삭제·숨김 글 좋아요 불가**.

### 댓글·대댓글 계약
- 댓글 + 1단 대댓글까지만. 대댓글에 또 답글 = 2단으로 안 내려가고 동일 1단 처리 **또는 서버 거부**(계약 고정 — 현재 백엔드는 `답글에는 다시 답글 불가`로 **거부**).
- 삭제된 부모 댓글에 답글 금지(현재 백엔드 거부 O). 본인 댓글만 삭제. 관리자 숨김·복구. **차단 사용자 글·댓글 서버 필터링**.
