## 핵심 기능 영역

### 📷 카드 스캐너
- DINOv2 + FAISS 기반 카드 인식 (EN/JP/KO ~10,237장 카탈로그)
- **자산 등록 단일 게이트** — 스캐너로만 등록, 수동 검색 fallback 없음
- 앞면 신원검증(엄격) + 뒷면 면판정(완화)

### 💼 포트폴리오 / 자산
- 보유 카드 관리, 그레이딩 연동
- 카드 이미지: `resolveCardImageUrl` 전역함수, S3 `cards/v1` → CloudFront 서빙

### 💰 KO 시세 시스템
- 예상가(KO_ESTIMATED) = JP×비율 + chase floor + EN→JP 브릿지 + DAANGN obs + MANUAL_FLOOR
- 카드 상세 시세 차트(koLine) + 급변동 탭(JP raw % 투영)
- `price_confidence` 라벨 (시세 vs 예상가치 구분)
- 일일 batch cron (KST 23:50/23:52/23:55), 불변식 KO<JP·KO<EN 검증

### 🤝 거래
- 호가창(read view + footer CTA), 매수 주문(BuyOrder), 양방향 채팅(이미지 메시지)
- 신고 / 모더레이션, 공용 신고 시트
- 구매글 상세(판매글 대칭)

### 🎖 그레이딩
- AI 그레이딩 → 실카드 검증(scanner cardId 매칭) + `cardVerified` 배지
- 외부 등급사 표기 PSA / BRG 만

### 🔎 검색 · 카드 상세
- 검색 결과 = 거래 시세 리스트 동일 레이아웃
- 찜(관심) 하트, 상세 헤더 아이콘 스크롤 fade

### 👤 계정 · 안전
- Apple 로그인, **전화번호 인증**(거래 진입 게이트), **만 14세 연령 게이트**(self-declared)
- 탈퇴: soft-delete + 3개월 보존, 재로그인 부활 차단
- **정지(suspend)** 시스템 + 즉시잠금 + 이의신청 페이지

### 🛠 관리자 (admin web)
- 대시보드, 신고/문의/이의신청/가격이상 큐
- 운영 관측성 Phase 1 (운영 로그 뷰어 + 유저 경고)

### 🏗 인프라
- **CloudFront 마이그레이션** (`BASE_URL` + 카드 CDN) — 해외 리뷰어 도달성 fix
- **점검(maintenance) 게이트** — S3 `app-config/maintenance.json` 전역 스위치 (fail-open)
- Caffeine 캐시 (price-summary 30분 TTL)

### ⚖️ 법무
