## 🎯 이번 버전 핵심: 강제 업데이트 게이트

**왜**: 백엔드가 계속 진화 → 구버전 클라가 깨질 수 있음 (1.0.1 `language DEFAULT 'KO'` 방어가 그 증거). 현재 버전 강제/안내 메커니즘이 **전무** (점검 게이트는 버전 무관 전역 스위치).
**제약**: 게이트는 "그게 들어간 버전부터" 효과 → 1.0.2부터 보호 시작. 1.0/1.0.1 사용자는 앱스토어 수동 업뎃 의존.

### 설계 확정 (Codex 리뷰 반영)
- **config 분리**: `app-config/version.json` (maintenance.json과 별도 파일 — blast radius 분리)
  ```json
  { "minBuild": <int>, "latestBuild": <int>,
    "iosStoreUrl": "https://apps.apple.com/app/idTBD",
    "enabled": true, "message": "..." }
  ```
- **상태머신 우선순위**: `maintenance > hardGate(build<minBuild) > softPrompt(build<latestBuild) > normal`
- **파괴적 오설정 가드** (필수 3종):
  - 킬스위치 `enabled:false` (S3 재업로드 = 전원 즉시 해제, 1차 복구)
  - 클램프 `effectiveMin = min(minBuild, latestBuild)`
  - sanity ceiling (`minBuild > 209912312359` → 0 취급) + 모든 parse 에러 **fail-open**
- **App Store 심사 안전**: ★`minBuild`는 **이미 승인·배포된 빌드**로만. 심사 윈도우엔 `enabled:false` 유지 → "Ready for Sale" 후 true. (minBuild ≥ 심사중 빌드면 리뷰어 막혀 자동반려)
- **구현**: `package_info_plus` 추가(iOS `buildNumber`=CFBundleVersion, `int.tryParse`, null이면 fail-open). 위젯 = `MaintenanceGate(child: VersionGate(child: child))` 별도 형제. url_launcher `LaunchMode.externalApplication`. 소프트 dismiss = SharedPreferences `dismissedBuild`.
- 상세 설계: 이 세션 Codex 리뷰 참조.
