# 등급/거래 UI 버그 트래커 (1.0.1 이후 폴리시)

> 2026-06-11. 등급 카드 거래 기능 테스트 중 발견. 하나씩 쳐낸다. 빌드/배포는 묶어서.
> 작업 브랜치 = `feat/graded-grade-10-9`(FE) / 배포브랜치(BE).

## 🐞 버그 목록

### B1 — 보드/시세가 보유 등급 아니라 RAW로 뜸
- 증상: PSA 9 등록 카드인데 거래/시세 보드가 RAW/PSA/BRG 다 뜨고 기본 RAW. "내가 등록한 것만 떠야" (판매는 락됨, 보드만 문제).
- 근본: ① 등급(PSA) 시세 데이터 미구축 → graded 칩/차트 없음 → RAW fallback. ② initState grade-default가 데이터 없는 등급도 선택(취약).
- 결정 필요: grade-default(보드→보유등급) **롤백**(보드 항상 RAW=안전)? vs graded 시세 데이터까지 제대로 구축? → grade-8/PSA 레인과 한 묶음.
- 상태: ⬜ 미해결 (결정 대기)

### B2 — 차트 "데이터 없음"
- 증상: 일부 카드(PROMO 메타몽 등) 시세 차트가 "데이터 없음".
- 근본 추정: 해당 카드 차트 time-series 부재 / 또는 grade-default가 무데이터 등급 선택해 빈 차트. (제크로무는 차트 나옴 — 카드별 데이터 문제 가능)
- 상태: ⬜ 조사 필요 (카드별 데이터 vs 회귀 구분)

### B3 — 가격 범위 "100원 ~ 100원" (low==high)
- 증상: 제크로무 ex 시세 "100원 ~ 100원"인데 대표가 160원. low==high로 범위가 안 벌어짐.
- 근본 확정: `GlobalPriceService` koLow/koHigh = `roundPrice(koMid×0.85/1.15)`. `roundPrice`가 <10000을 100원 내림 → 저가 카드(koMid≈160)는 136·184가 둘 다 100으로 붕괴. (koMid=시세 본체는 정상)
- 수정(BE): 밴드 ±15%→**±20%** + 붕괴(lo==hi) 시 **10원 단위 finer 라운딩**(큰 카드는 기존 100원 단위 유지). 160 → 130~190.
- 상태: 🔧 **수정완료** (BE, 배포 대기) — Codex 리뷰 후 cherry→prod

### B4 — RAW 칩 "0천 ~ 0천" (천 단위 포맷 깨짐)
- 증상: RAW 칩이 "0천 ~ 0천" (1000원 미만 값이 천 단위로 0천 표시).
- 근본 확정: `_formatCompactWon`이 <1000을 `${price~/1000}천` = '0천'으로. 
- 수정(FE): <1000=원 단위(콤마), 1000~9999=X.X천, ≥10000=만. '0천' 제거.
- 상태: 🔧 **수정완료** (FE, 빌드 대기)

### B5 — moat(scan_capture) 새 스캔에 안 쌓임
- 증상: nightfury scan_capture 총 1개(아침 10:38)뿐. 오늘 여러 번 스캔했는데 새 캡처 0.
- 근본 추정: `captureAsync`(fire-and-forget, 실패 시 조용히 skip) 미동작 — 크롭 반환/품질·cap·dedup/저장 실패.
- 상태: ⬜ 조사 필요 (moat 전략 핵심)

### B6 — 카드 삭제 vs 판매글 삭제 UX 혼동
- 증상: 카드 상세 🗑로 "카드 삭제"한 줄 알았는데 판매글만 삭제됨. (활성 판매글 있으면 자산 삭제 차단됨)
- 근본: 카드 상세 🗑 동작이 카드/판매글 중 뭘 지우는지 불명확.
- 상태: ⬜ UX 명확화 필요

### B7 — 언어 탭(KO/JP/EN)이 데이터 없는 언어까지 다 뜸
- 증상: KO만 있는 카드(메타몽 프로모)인데 등록 시트 언어 탭에 JP/EN까지 뜸.
- 제안 기준: **차트(시세) 데이터 있는 언어만** 탭 노출. (사용자: "차트 기준으로 잡으면 쉬움")
- 상태: ⬜ 미해결

### B8 — 안내 문구가 PSA10 고정 (PSA9 등록인데)
- 증상: PSA **9** 등록인데 내 자산 탭 안내가 "**PSA 10** 시세 데이터가 아직 없어 RAW 시세 기준으로 표시됩니다."
- 근본: 안내 문구가 등급(gradeValue) 안 반영하고 PSA10 하드코딩/고정.
- 상태: ⬜ 미해결 (문구 — 빠름)

### B9 — 거래 보드 등급 선택이 판매/주문 시트에 안 이어짐 (중간단계 스킵)
- 증상: 거래 보드에서 PSA 9 선택 상태인데, 판매글/주문 시트 열면 RAW/PSA/BRG **재선택(RAW 기본)** 으로 뜸. 보드 컨텍스트가 시트에 안 전달, 중복 등급 선택기. "중간 단계가 빠지고 이어짐."
- 근본: 보드 `_selectedGlobalGrade` ↔ 시트 로컬 cardStatus/grade 상태 미연결.
- 상태: ⬜ 미해결
