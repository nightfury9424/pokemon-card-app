# 고객 문의 답변 틀 (표준 톤)

2026-06-14 사용자 확정. 고객 문의(특히 기능 제안·버그·개선 건의) 답변은 **이 톤·구조**로 작성한다.
실제 채택 답변(Sua님 등급 정렬 건의)을 레퍼런스로 둔다.

## 구조 (5단)
1. **인사 + 감사** — "OO님, 안녕하세요! 포켓폴리오입니다 😊 / 소중한 의견 감사해요!"
2. **상대 띄워주기** — 의견의 구체성·날카로움을 인정 (겸손하게 쓴 분이면 더 살려줌).
3. **공감 + 무엇을 했는지** — 지적이 맞았음을 인정하고, 바로 수정했음을 구체적으로.
4. **현실 caveat(정직)** — iOS는 애플 심사 승인 후 반영 → "다음 업데이트에 곧장" (날짜 하드약속 X).
5. **마무리 감사 + 열린 초대** — "덕분에 한 걸음 좋아졌다 / 언제든 편하게 들려주세요" — 포켓폴리오 드림.

원칙: 따뜻하게, 사람냄새. 이모지 절제. 시간 약속은 여유. 책임은 정직하게(심사 의존성 등).

## 레퍼런스 답변 (Sua — 등급 정렬 SR>AR)
```
Sua님, 안녕하세요! 포켓폴리오입니다

소중한 의견 남겨주셔서 정말 감사해요! 포린이라고 하셨지만, 이 부분은 오래 모으신 분들도 무심코 지나치기 쉬운 디테일인데 짚어주셔서 감사합니다!

말씀하신 그대로예요. 기존엔 SAR·UR 다음에 AR이 오고 SR이 한참 아래에 있다 보니, 마치 SR 기록이 사라진 것처럼 보일 수 있었어요. 의견 주신 직후 바로 SR이 AR 위에 오도록 등급 정렬 순서를 수정했습니다.

다만 iOS 앱은 애플 심사 승인을 거쳐야 반영되는 구조라, 지금 바로는 못 보여드리지만 다음 업데이트에 곧장 담아 올려드릴게요. 업데이트 후엔 내 자산에서 SR 카드들이 제자리에 잘 자리 잡고 있을 거예요!

Sua님 덕분에 포켓폴리오가 또 한 걸음 좋아졌습니다. 앞으로도 좋은 생각이나 불편한 점 있으면 언제든 편하게 들려주세요. 항상 감사합니다!
— 포켓폴리오 드림
```

## 카드 추가 요청 — 해결 완료 답변 틀

카드 추가 요청을 **실제로 추가 완료**했을 때 보내는 happy-path 회신. (앱 내 알림으로 전달.)
2026-06-15 사용자 확정 톤 — **이모지 절제 + 느낌표 위주 + 사람냄새**. (이제 카드추가 답변은 전부 이 틀.)

### 구조
1. **인사** — "{닉}님, 안녕하세요! 포켓폴리오입니다!" (이모지 X, 느낌표).
2. **(시간대 조건) 시간 인사** — **밤 22시~아침 8시(KST) 발송 시에만** "늦은시간에 죄송합니다!" 추가. 그 외(낮 8~22시)엔 **생략**. (답변 자동화 시 서버 발송시각 KST 기준으로 자동 분기.)
3. **감사 + 의미** — "{카드명} 추가 요청 감사합니다! 알려주신 덕분에 카탈로그가 한 칸씩 채워집니다." (일본/옛날 카드면 한 번 더 띄워줌.)
4. **✅ 처리결과 + 안내** — "요청하신 {카드명}({세트}·{레어도}·{번호}) 방금 추가 완료했어요! 지금 앱에서 검색하면 바로 보여요." + {발매판} 기준 등록 / 시세 **곧 채워짐**(하드약속 X) / (KO만) 이미지 **해외판 참고일 수 있음**.
5. **마무리** — "또 빠진 카드 보이면 언제든 편하게 요청 주세요." → — 포켓폴리오 드림.

플레이스홀더 = {닉}{카드명}{세트}{레어도}{번호}{발매판}.

### 완성본 — 파라블레이즈 (한국판 AR · 포빈이님)
```
포빈이님, 안녕하세요! 포켓폴리오입니다!
늦은시간에 죄송합니다!

파라블레이즈 추가 요청 감사합니다! 알려주신 덕분에 카탈로그가 한 칸씩 채워집니다.

요청하신 파라블레이즈(초전브레이커 · AR · 109/106) 방금 추가 완료했어요! 지금 앱에서 "파라블레이즈" 검색하면 바로 보이실 거예요. 한국판 기준으로 등록했고, 예상 시세도 곧 채워질 거예요. (카드 이미지는 해외판 참고 이미지로 먼저 보일 수 있는 점 양해 부탁드려요!)

또 빠진 카드 보이면 언제든 편하게 요청 주세요. 하나하나 채워나갈게요. 감사합니다!
— 포켓폴리오 드림
```

### 완성본 — 흉내내기 피카츄 (일본판 단독 프로모 · 럭키박스님)
```
럭키박스님, 안녕하세요! 포켓폴리오입니다!
늦은시간에 죄송합니다!

흉내내기 피카츄 추가 요청 감사합니다! 일본 프로모까지 꼼꼼히 챙겨주신 덕분에 카탈로그가 한 칸씩 채워집니다.

요청하신 흉내내기 피카츄(일본판 프로모 · 407/SM-P) 방금 추가 완료했어요! 지금 앱에서 "흉내내기 피카츄" 검색하면 바로 보이실 거예요. 일본 단독 프로모라 일본판 시세 기준으로 보여드리고, 시세 정보도 곧 채워질 거예요.

또 찾으시는 카드 있으면 언제든 편하게 요청 주세요. 감사합니다!
— 포켓폴리오 드림
```
