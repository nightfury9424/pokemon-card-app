## 🎯 한 줄 진단
지금은 **"토스 느낌 카드 포트폴리오"가 아니라 "딥다크 시세 터미널 + NFT 갤러리"**.
(#04080F 배경 + rarity 글로우 + blur hero + 다층 그림자 + 빨강/파랑 % = Upbit/바이낸스 느낌)

## ★최상위 정체성 결정 (사용자 몫)
**카드 아트·컬렉션 즐거움을 1순위로, 시세·거래는 KREAM식 정리된 보조 레이어로. + 토스 친근함(여백·단일 accent·낮은 장식).**
지금은 "트레이딩 다크"가 너무 세서 토스 느낌과 정면충돌. → 이걸 먼저 정해야 나머지가 풀림.

## 🔑 근본 = 2개 (7개는 여기서 파생)
1. **다크-트레이딩 톤 ↔ 토스 친근함이 싸움** (장식/색/밀도)
2. **카드 아트가 안 보임** ("이미지 없음" placeholder가 화면 지배)

## ⚡ Quick wins (1일 내)
1. 0% 수익률 전화면 회색 통일 (홈/자산 spotlight/그리드/상세 PnL)
2. 이미지 없는 카드를 홈 캐러셀·spotlight 대표에서 제외/후순위
3. 글로우·검정 오버레이·blur/shadow 강도 30~50%↓

## 🎲 Bigger bets
1. KO 이미지 전략 재설계 — cardVerified 실사진 / 유저 업로드 / 세트 placeholder / JP·EN fallback 우선순위 (★IP리스크·moat)
2. 홈 IA 분기 — "내 포트폴리오 홈" vs "시장 발견 홈" 상태별

## 🚨 토스 느낌과 가장 어긋나는 것
